# floating-text demo
ar karaoke text demo

## how it works
this demo uses webxr hit-test to find real-world surfaces & place a floating text plane in ar. a canvas is rendered with the lyric, converted into a texture, mapped onto a plane in 3d space, positioned at the reticle’s hit-test pose, & billboarded toward the camera each frame.

## what it will be used for
this is the minimal prototype for an ar karaoke system where lyrics appear anchored in the environment, stay readable as users move, & can be dynamically updated during playback.
